# Haval H3 Telemetry

Неофициальное бесплатное Android-приложение для вывода параметров автомобиля на приборную панель Haval H3 со штатной мультимедийной системой.

> [!IMPORTANT]
> Приложение проверено на Haval H3 со штатной ГУ Android 9, код проекта 203. Совместимость с другими автомобилями и версиями прошивки не гарантируется. Проект не связан с Great Wall Motor, Haval или их официальными представителями.

## Возможности

- вывод данных на дополнительный дисплей приборной панели;
- остаток топлива в литрах;
- температура охлаждающей жидкости;
- напряжение 12-вольтового аккумулятора;
- список дополнительных сигналов, доступных в системном сервисе ГУ;
- отдельное включение и отключение каждого показателя;
- настройка позиции и размера шрифта каждого показателя;
- сохранение настроек между запусками;
- автоматический запуск после загрузки головного устройства.

## Совместимость

Подтверждённая конфигурация:

- Haval H3;
- штатная мультимедийная система Android 9;
- код проекта 203;
- приборная панель 1920 × 720;
- системный сервис `gwm_adapter`;
- разрешение `com.gwm.android.adapter.permission.GET_DATA`.

На другой модели GWM/Haval/Tank/ORA приложение заработает только при совместимом системном интерфейсе и конфигурации дисплеев.

## Установка

1. Скачайте APK из раздела [Releases](../../releases/latest).
2. Подключитесь к ГУ через ADB.
3. Установите или обновите приложение:

```powershell
adb install -r .\haval-h3-telemetry.apk
```

4. Запустите приложение:

```powershell
adb shell monkey -p app.havalh3.telemetry -c android.intent.category.LAUNCHER 1
```

На главном экране оставлены три общие настройки: **Автозагрузка**, **Показать** и **Скрыть**. Нажмите на строку нужного датчика, чтобы включить его, изменить положение или размер шрифта.

## Сборка из исходников

Требования:

- JDK 17;
- Android SDK 35;
- Gradle 8.9;
- Android Gradle Plugin 8.7.3.

```bash
gradle --no-daemon assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

CI автоматически проверяет debug-сборку при каждом push и pull request. Подписанные APK публикуются владельцем проекта в GitHub Releases. Ключ подписи и пароли в репозитории не хранятся.

## Диагностика

Проверка разрешения:

```powershell
adb shell dumpsys package app.havalh3.telemetry |
  Select-String -Pattern "GET_DATA|grantedPermissions" -Context 1,5
```

Журнал приложения:

```powershell
adb logcat -c
adb logcat | Select-String "H3GwmAdapter|H3TelemetryService|Permission Denial|SecurityException"
```

Проверка автозагрузки:

```powershell
adb logcat -d |
  Select-String "H3TelemetryBoot|H3TelemetryService|BOOT_COMPLETED|QUICKBOOT_POWERON"
```

Автозагрузка реагирует на обычную, раннюю и быструю загрузку Android. Если дисплей приборной панели ещё не готов, приложение повторяет запуск в течение двух минут.

## Ограничения и безопасность

- Приложение использует системный интерфейс штатной ГУ, который может измениться после обновления прошивки.
- Экран приборной панели выбирается по конфигурации Haval H3; на другом устройстве расположение элементов может отличаться.
- Проверяйте новые версии на неподвижном автомобиле. Не настраивайте интерфейс во время движения.
- Приложение не отправляет телеметрию в интернет и не содержит рекламы или аналитики.
