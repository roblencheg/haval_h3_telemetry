# Haval H3 Telemetry

Неофициальное бесплатное Android-приложение для вывода автомобильной телеметрии на приборную панель Haval H3 со штатной мультимедийной системой.

> [!IMPORTANT]
> Приложение проверено на Haval H3 со штатной ГУ Android 9 и кодом проекта 203. Совместимость с другими автомобилями и версиями прошивки не гарантируется. Проект не связан с Great Wall Motor, Haval или их официальными представителями.

## Возможности

- вывод данных на дополнительный дисплей приборной панели;
- остаток топлива в литрах;
- температура охлаждающей жидкости;
- напряжение 12-вольтового аккумулятора;
- дополнительные сигналы, доступные через системный сервис ГУ;
- текущая дата;
- отдельное включение и отключение каждого показателя;
- настройка положения и размера шрифта каждого показателя;
- сохранение настроек между обновлениями и перезапусками;
- автоматический запуск после загрузки головного устройства;
- ручные команды «Показать» и «Скрыть».

## Совместимость

Подтверждённая конфигурация:

- Haval H3;
- штатная мультимедийная система Android 9;
- код проекта 203;
- приборная панель 1920 × 720;
- системный сервис `gwm_adapter`;
- разрешение `com.gwm.android.adapter.permission.GET_DATA`.

На другой модели GWM, Haval, Tank или ORA приложение заработает только при совместимом системном интерфейсе и конфигурации дисплеев.

## Установка и обновление

1. Скачайте APK из раздела [Releases](../../releases/latest).
2. Подключитесь к ГУ через ADB.
3. Установите или обновите приложение:

```powershell
adb install -r .\H3Telemetry-v1.7.0-release.apk
```

4. Запустите приложение:

```powershell
adb shell monkey -p app.havalh3.telemetry -c android.intent.category.LAUNCHER 1
```

Если уже установлена версия 1.0 или новее с постоянной release-подписью, удалять приложение перед обновлением не нужно. Координаты, размеры шрифтов и выбранные показатели сохранятся.

## Использование

На главном экране доступны общие команды **Автозагрузка**, **Показать** и **Скрыть**.

Нажмите на строку нужного показателя, чтобы:

- включить или отключить его на приборной панели;
- изменить координаты X и Y;
- выбрать шаг перемещения;
- изменить размер шрифта;
- сбросить настройки этого показателя.

Автозагрузка включена по умолчанию. Приложение обрабатывает обычную, раннюю и быструю загрузку Android. Если дополнительный дисплей ещё не готов, запуск приборки повторяется в течение десяти минут.

## Диагностика

Проверка разрешения системного сервиса:

```powershell
adb shell dumpsys package app.havalh3.telemetry |
  Select-String -Pattern "GET_DATA|grantedPermissions" -Context 1,5
```

Журнал подключения и автозагрузки:

```powershell
adb logcat -d |
  Select-String "H3GwmAdapter|H3TelemetryService|H3TelemetryBoot|SecurityException"
```

## Сборка из исходников

Требования:

- JDK 17;
- Android SDK 35;
- Gradle 8.9;
- Android Gradle Plugin 8.7.3.

```bash
gradle --no-daemon assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

CI проверяет debug-сборку при каждом push и pull request. Подписанные APK публикуются владельцем проекта. Ключ подписи и пароли в публичном репозитории не хранятся.

## Ограничения и безопасность

- Приложение использует системный интерфейс штатной ГУ, который может измениться после обновления прошивки.
- Экран приборной панели выбирается по конфигурации Haval H3; на другом устройстве расположение элементов может отличаться.
- Приложение использует только необходимые системные разрешения, не отправляет телеметрию в интернет, не содержит рекламы и аналитики.
- Проверяйте новые версии на неподвижном автомобиле. Не настраивайте интерфейс во время движения.
